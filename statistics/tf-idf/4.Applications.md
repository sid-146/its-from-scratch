# Vector Space Model and Similarity Computation using TF-IDF

This section explains how TF-IDF representations allow documents to be compared mathematically. The concept used is called the **Vector Space Model (VSM)**.

---

# 4.1 Motivation for the Vector Space Model

- After computing TF-IDF, each document is represented as a **numerical vector**.
- Machine learning and information retrieval systems require a way to **measure similarity between documents**.
- The Vector Space Model provides a mathematical framework where:
    - Documents are treated as **vectors in a high-dimensional space**.
    - Each dimension corresponds to a **term in the vocabulary**.

- The TF-IDF value becomes the **coordinate value** in that dimension.

Therefore:

- If the vocabulary size is (V), every document becomes a vector in **(V)-dimensional space**.

Example:

Vocabulary

```
[machine, learning, deep, ai]
```

Document:

```
machine learning machine
```

TF-IDF representation:

| Term     | TF-IDF |
| -------- | ------ |
| machine  | 0.6    |
| learning | 0.3    |
| deep     | 0      |
| ai       | 0      |

Vector form:

```
D = [0.6, 0.3, 0, 0]
```

---

# 4.2 Geometric Interpretation

- In the vector space model:
    - Each document corresponds to a **point in a high-dimensional space**.

- Documents with similar topics will have **similar TF-IDF vectors**.
- Therefore these points will lie **close to each other in the vector space**.

Conceptually:

- Documents about **machine learning** cluster together.
- Documents about **biology** cluster elsewhere.

Distance or angle between vectors indicates **document similarity**.

---

# 4.3 Problem with Euclidean Distance

One naive way to measure similarity is **Euclidean distance**.

However Euclidean distance has limitations:

- It is sensitive to **document length**.
- Longer documents tend to have **larger vector magnitudes**.

Example:

Two documents may contain the same terms but different lengths.

```
Doc1: machine learning
Doc2: machine learning machine learning machine learning
```

Their vectors will have different magnitudes.

But semantically they are **very similar**.

Therefore Euclidean distance may give misleading results.

To solve this, cosine similarity is used.

---

# 4.4 Cosine Similarity

Cosine similarity measures the **angle between two vectors** instead of their distance.

$$\cos(\theta)=\frac{A\cdot B}{||A||,||B||}$$

Where:

- $A$ and $B$ are TF-IDF vectors
- $(A \cdot B)$ is the **dot product**
- $||A||$ and $||B||$ are vector magnitudes
- $(\theta)$ is the **angle between the vectors**

---

# 4.5 Interpretation of Cosine Similarity

Cosine similarity ranges between **0 and 1** for TF-IDF vectors.

| Value | Interpretation           |
| ----- | ------------------------ |
| 1     | Documents are identical  |
| 0     | Documents share no terms |

Key idea:

- If two documents share many important words, their vectors point in **similar directions**.
- Therefore the angle between them becomes **small**.
- Cosine similarity becomes **close to 1**.

---

# 4.6 Example Calculation

Vocabulary:

```
[machine, learning, deep]
```

TF-IDF vectors:

Document A:

```
A = [0.6, 0.8, 0]
```

Document B:

```
B = [0.5, 0.7, 0.2]
```

---

### Step 1 — Dot Product

$$
A \cdot B = (0.6 \times 0.5) + (0.8 \times 0.7) + (0 \times 0.2)
$$

$$
= 0.30 + 0.56 + 0
$$

$$
= 0.86
$$

---

### Step 2 — Vector Magnitudes

Magnitude of (A)

$$
||A|| = \sqrt{0.6^2 + 0.8^2}
$$

$$
= \sqrt{0.36 + 0.64}
$$

$$
= 1
$$

Magnitude of (B)

$$
||B|| = \sqrt{0.5^2 + 0.7^2 + 0.2^2}
$$

$$
= \sqrt{0.25 + 0.49 + 0.04}
$$

$$
= \sqrt{0.78}
$$

$$
\approx 0.883
$$

---

### Step 3 — Cosine Similarity

$$
cos(\theta) = \frac{0.86}{1 \times 0.883}
$$

$$
\approx 0.974
$$

Interpretation:

- The documents are **very similar**.

---

# 4.7 Why Cosine Similarity Works Well with TF-IDF

Cosine similarity has several advantages:

- It ignores **vector magnitude differences**.
- It focuses on **direction of vectors**.
- It works well for **high-dimensional sparse vectors**.
- It is computationally efficient.

This makes cosine similarity ideal for **text similarity problems**.

---

# 4.8 Practical Applications

The TF-IDF + cosine similarity framework is widely used in:

### Search Engines

- Query is converted to TF-IDF vector.
- Documents are ranked by cosine similarity.

### Document Clustering

- Documents with similar vectors are grouped together.

### Text Classification

- TF-IDF vectors become features for classifiers.

### Duplicate Detection

- Highly similar documents can be detected automatically.

---

# Section Summary

The Vector Space Model enables TF-IDF to be used for document comparison.

Key concepts:

- Documents are represented as **vectors of TF-IDF weights**.
- Similarity between documents is measured using **cosine similarity**.
- The angle between vectors determines **semantic similarity**.
- This approach forms the foundation of many **classical NLP and search systems**.
