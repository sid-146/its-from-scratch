# Step-by-Step Numerical Example of TF-IDF Calculation

This section demonstrates how TF-IDF values are calculated manually using a small corpus. The goal is to clearly show each intermediate step.

---

# 3.1 Example Corpus

Consider the following three documents.

```
D1: "machine learning is powerful"
D2: "deep learning drives ai"
D3: "machine learning improves systems"
```

Total number of documents:

$$
[
N = 3
]
$$

---

# 3.2 Step 1 — Build Vocabulary

The vocabulary consists of all unique words in the corpus.

Vocabulary:

| Term     |
| -------- |
| machine  |
| learning |
| is       |
| powerful |
| deep     |
| drives   |
| ai       |
| improves |
| systems  |

Total vocabulary size = **9**

Each document will eventually be represented as a **vector of length 9**.

---

# 3.3 Step 2 — Compute Term Frequency (TF)

Count the number of times each word appears in each document.

### Document D1

```
machine learning is powerful
```

| Term     | Frequency |
| -------- | --------- |
| machine  | 1         |
| learning | 1         |
| is       | 1         |
| powerful | 1         |

Total words = 4

Normalized TF:

| Term     | TF         |
| -------- | ---------- |
| machine  | 1/4 = 0.25 |
| learning | 1/4 = 0.25 |
| is       | 1/4 = 0.25 |
| powerful | 1/4 = 0.25 |

All other vocabulary terms have TF = 0.

---

### Document D2

```
deep learning drives ai
```

| Term     | Frequency |
| -------- | --------- |
| deep     | 1         |
| learning | 1         |
| drives   | 1         |
| ai       | 1         |

Total words = 4

Normalized TF:

| Term     | TF   |
| -------- | ---- |
| deep     | 0.25 |
| learning | 0.25 |
| drives   | 0.25 |
| ai       | 0.25 |

---

### Document D3

```
machine learning improves systems
```

| Term     | Frequency |
| -------- | --------- |
| machine  | 1         |
| learning | 1         |
| improves | 1         |
| systems  | 1         |

Total words = 4

Normalized TF:

| Term     | TF   |
| -------- | ---- |
| machine  | 0.25 |
| learning | 0.25 |
| improves | 0.25 |
| systems  | 0.25 |

---

# 3.4 Step 3 — Compute Document Frequency (DF)

Document Frequency counts how many documents contain each word.

| Term     | DF  |
| -------- | --- |
| machine  | 2   |
| learning | 3   |
| is       | 1   |
| powerful | 1   |
| deep     | 1   |
| drives   | 1   |
| ai       | 1   |
| improves | 1   |
| systems  | 1   |

Interpretation:

- **learning appears in every document**
- therefore it will receive a **low IDF weight**

---

# 3.5 Step 4 — Compute Inverse Document Frequency (IDF)

Formula:

$$
IDF(t) = \log \left(\frac{N}{DF(t)}\right)
$$

Total documents:

$$N = 3$$

---

### IDF for "learning"

$$IDF(learning) = \log \left(\frac{3}{3}\right)$$

$$= \log(1) = 0$$

Interpretation:

- The word **learning appears everywhere**, so it has **no discriminative power**.

---

### IDF for "machine"

$$
IDF(machine) = \log \left(\frac{3}{2}\right)
$$

$$\approx 0.176$$

---

### IDF for rare words

For words appearing only once:

Example:

$$IDF(deep) = \log \left(\frac{3}{1}\right)$$

$$\approx 1.098$$

These terms are **more informative**.

---

# 3.6 Step 5 — Compute TF-IDF

TF-IDF multiplies TF and IDF.

$$TFIDF(t,d)=TF(t,d)\times IDF(t)$$

---

### Example: TF-IDF in Document D1

Word: **machine**

TF:

$$TF = 0.25$$

IDF:

$$0.176$$

TF-IDF:

$$0.25 \times 0.176 = 0.044$$

---

### Word: learning

TF:

$$0.25$$

IDF:

$$0$$

TF-IDF:

$$0$$

Interpretation:

- Even though **learning appears frequently**, it receives **zero weight** because it appears in all documents.

---

### Word: powerful

TF:

$$
0.25
$$

IDF:

$$
1.098
$$

TF-IDF:

$$
0.25 \times 1.098 = 0.274
$$

Interpretation:

- The word **powerful** becomes very important because it appears in **only one document**.

---

# 3.7 Final TF-IDF Representation

Example for **Document D1**

| Term     | TF-IDF |
| -------- | ------ |
| machine  | 0.044  |
| learning | 0      |
| is       | 0.274  |
| powerful | 0.274  |
| deep     | 0      |
| drives   | 0      |
| ai       | 0      |
| improves | 0      |
| systems  | 0      |

Each document is now represented as a **numeric vector**.

Example:

```
D1 vector = [0.044, 0, 0.274, 0.274, 0, 0, 0, 0, 0]
```

This vector representation can be used by machine learning algorithms.

---

# 3.8 Key Observations

- Words appearing in **every document get very low TF-IDF values**.
- Words appearing **rarely across documents get high weights**.
- TF-IDF emphasizes **informative words**.
- Each document becomes a **vector in a high-dimensional space**.

This representation allows algorithms to compute:

- similarity
- clustering
- classification
- document ranking.

---

# Section Summary

The TF-IDF calculation process follows these steps:

1. Build vocabulary from the corpus.
2. Compute Term Frequency for each document.
3. Compute Document Frequency across the corpus.
4. Calculate Inverse Document Frequency.
5. Multiply TF and IDF to obtain the TF-IDF weight.

The result is a **numerical vector representation of text documents**.
