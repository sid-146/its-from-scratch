# Mathematical Formulation of TF, IDF and TF-IDF

# 2.1 Mathematical Notation

Before defining TF-IDF formally, define the basic components of a document collection.

- Let the **corpus** be a collection of documents.

$$
[
D = {d_1, d_2, d_3, ..., d_N}
]
$$

- (N) represents the **total number of documents** in the corpus.

- Let (t) represent a **term (word)** from the vocabulary.

- Let $(f\_{t,d})$ represent the **frequency of term (t) in document (d)**.

Example:

Document

```
d1 = "machine learning improves machine intelligence"
```

Word counts:

| Term         | Frequency |
| ------------ | --------- |
| machine      | 2         |
| learning     | 1         |
| improves     | 1         |
| intelligence | 1         |

Therefore:

[
f_{machine,d1} = 2
]

---

# 2.2 Term Frequency (TF)

Term Frequency measures **how often a term occurs in a document**.

The intuition:

- Words appearing many times in a document are likely important to that document.

### Basic Term Frequency

The simplest definition is the **raw count**.

[
TF(t,d) = f_{t,d}
]

where

- (f\_{t,d}) = number of times term (t) appears in document (d)

However, raw counts create problems because **long documents naturally contain more words**.

To correct this, TF is often **normalized by document length**.

### Normalized Term Frequency

[
TF(t,d) = \frac{f_{t,d}}{\sum_{t' \in d} f_{t',d}}
]

Where:

- numerator = frequency of term (t)
- denominator = total number of words in the document

This converts TF into a **probability-like measure**.

Interpretation:

- It represents the **relative importance of a word within a document**.

---

# 2.3 Example of Term Frequency

Document:

```
d1 = "data science uses data analysis"
```

Word counts:

| Term     | Count |
| -------- | ----- |
| data     | 2     |
| science  | 1     |
| uses     | 1     |
| analysis | 1     |

Total words = 5

Term Frequency values:

| Term     | TF         |
| -------- | ---------- |
| data     | 2/5 = 0.40 |
| science  | 1/5 = 0.20 |
| uses     | 1/5 = 0.20 |
| analysis | 1/5 = 0.20 |

Interpretation:

- The word **data** is most important within this document.

However, TF alone is insufficient.

Why?

Because some words appear **frequently in almost every document**.

Example:

- the
- is
- and
- of

These words will always have high TF values.

Therefore we need a mechanism to **reduce their importance globally**.

---

# 2.4 Document Frequency (DF)

To address this, we define **Document Frequency**.

Document Frequency measures:

- **how many documents contain a term**

Mathematically:

[
DF(t) = |{d \in D : t \in d}|
]

This means:

- Count the number of documents that contain term (t).

Example corpus:

```
D1: machine learning models
D2: deep learning algorithms
D3: machine learning systems
```

Document Frequency:

| Term       | DF  |
| ---------- | --- |
| machine    | 2   |
| learning   | 3   |
| models     | 1   |
| deep       | 1   |
| algorithms | 1   |
| systems    | 1   |

Observation:

- **learning appears in every document**
- therefore it is less useful for distinguishing documents.

---

# 2.5 Inverse Document Frequency (IDF)

To penalize very common words, we define **Inverse Document Frequency**.

The intuition:

- Rare terms should receive **higher importance**.
- Common terms should receive **lower importance**.

Mathematically:

[
IDF(t) = \log \left(\frac{N}{DF(t)}\right)
]

Where:

- (N) = total number of documents
- (DF(t)) = number of documents containing term (t)

Interpretation:

- If a word appears in many documents → denominator large → IDF small.
- If a word appears in few documents → denominator small → IDF large.

---

# 2.6 Example of IDF

Corpus:

```
D1: machine learning models
D2: deep learning algorithms
D3: machine learning systems
```

Total documents:

[
N = 3
]

Document Frequencies:

| Term     | DF  |
| -------- | --- |
| machine  | 2   |
| learning | 3   |
| models   | 1   |

IDF values:

### Machine

[
IDF(machine) = \log\left(\frac{3}{2}\right)
]

### Learning

[
IDF(learning) = \log\left(\frac{3}{3}\right) = \log(1) = 0
]

### Models

[
IDF(models) = \log\left(\frac{3}{1}\right)
]

Interpretation:

- **learning** receives very low weight because it appears everywhere.
- **models** receives high weight because it appears rarely.

---

# 2.7 TF-IDF Weight

Finally, TF and IDF are combined.

The TF-IDF score is defined as:

TFIDF(t,d)=TF(t,d)\times IDF(t)

Where:

- (TF(t,d)) measures **importance inside the document**
- (IDF(t)) measures **rarity across documents**

Interpretation:

A word will receive a **high TF-IDF score** if:

- It appears many times in the document
- But appears in very few documents overall.

---

# 2.8 Log Scaling and Smoothed IDF

In practice, slightly modified formulas are used to improve stability.

### Log-Scaled Term Frequency

Instead of raw frequency:

[
TF(t,d) = 1 + \log(f_{t,d})
]

Reason:

- Prevents very frequent terms from dominating the score.

---

### Smoothed IDF

To avoid division by zero:

[
IDF(t) = \log\left(\frac{N+1}{DF(t)+1}\right) + 1
]

This is commonly used in **scikit-learn**.

---

# 2.9 Mathematical Interpretation

TF-IDF can be interpreted as a **weighting function for vector space models**.

Each document becomes a vector:

[
d = (w_1, w_2, ..., w_V)
]

Where:

- (V) = vocabulary size
- (w_i) = TF-IDF weight of term (i)

This vector representation allows documents to be compared using:

- cosine similarity
- Euclidean distance
- clustering algorithms
- classification models.

---

# Section Summary

TF-IDF is built from two mathematical components:

Term Frequency

- Measures how frequently a term appears in a document.

Inverse Document Frequency

- Measures how rare the term is across the corpus.

Final weight

- TF multiplied by IDF produces a score that highlights **informative words while suppressing common words**.
